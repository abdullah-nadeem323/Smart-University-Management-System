# Smart University Management System (C++)

## 📌 Overview
The **Smart Management System** is a C++ console-based application that demonstrates **inheritance and access specifiers** using a real-world user hierarchy.  
The system models different user roles such as **Student**, **Teacher**, and **Admin**, all derived from a common **User** base class.

## 🎯 Purpose
This project is designed for **educational and academic use** to help understand:
- Inheritance in C++
- Base and derived class relationships
- Constructor and destructor calling order
- Code reuse through protected members

## 🧠 OOP Concepts Used
- Classes and Objects  
- Inheritance (Single Inheritance)  
- Protected access specifier  
- Constructors and Destructors  
- Function reuse through base class methods  
- Runtime object lifecycle demonstration  

## ✨ Features
- User authentication simulation (login & logout)
- Student course registration functionality
- Teacher marks uploading simulation
- Admin system management functionality
- Automatic constructor and destructor call tracing

## 🛠️ Technologies
- **Language:** C++
- **Paradigm:** Object-Oriented Programming
- **Platform:** Console Application
